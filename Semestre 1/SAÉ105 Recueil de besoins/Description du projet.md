# Recueil de besoins des étudiants de l’IUT de Villetaneuse

Projet réalisé dans le cadre de la SAÉ S1.05 à l’Université Sorbonne Paris Nord (IUT de Villetaneuse).

## Description

Ce projet consiste à réaliser une enquête afin d’identifier les besoins et les difficultés des étudiants de l’IUT de Villetaneuse et de déterminer les paramètres pouvant faciliter leur réussite dans leurs études.

Pour cela, nous avons élaboré un questionnaire portant sur différents aspects de la vie étudiante : l’organisation personnelle, le sommeil, les transports, les difficultés financières, les méthodes d’apprentissage, la communication avec les enseignants, les méthodes d’évaluation, les conditions d’étude ainsi que les attentes des étudiants.

Les réponses recueillies ont ensuite été analysées afin de mettre en évidence les principales tendances et problématiques rencontrées par les étudiants. Un rapport de synthèse a été réalisé avec des graphiques, une analyse des résultats et des propositions d’amélioration.

## Fonctionnalités

Le projet permet :

- de définir les besoins liés à la réussite des étudiants ;
- de concevoir un questionnaire d’enquête ;
- de recueillir les réponses des étudiants ;
- de réaliser des entretiens avec différents profils d’étudiants ;
- de synthétiser les réponses obtenues ;
- d’analyser les résultats de l’enquête ;
- de représenter les résultats sous forme de graphiques ;
- d'identifier les principales difficultés rencontrées par les étudiants ;
- de proposer des solutions et des améliorations adaptées aux besoins identifiés ;
- de réaliser des profils de type persona afin de représenter différentes situations étudiantes.

## Résultats

L’enquête a permis d’identifier plusieurs facteurs pouvant influencer la réussite des étudiants, notamment la qualité de l’enseignement, la communication avec les enseignants, l’accès aux ressources pédagogiques, la durée des cours, le sommeil, les transports et les conditions de travail.

Les résultats montrent notamment une forte demande pour un site centralisant les cours et pour une plateforme de communication avec les enseignants.
