# Installation de poste pour le développement

Projet réalisé dans le cadre de la SAE S1.03 à l’Université Sorbonne Paris Nord.

## Description

Ce projet consiste à installer et configurer un poste de travail dédié au développement informatique.

L’objectif était de mettre en place un environnement de travail complet permettant d’utiliser efficacement les outils et technologies nécessaires à l’apprentissage de la programmation durant la formation.

J’ai commencé par installer un système d’exploitation Linux sur les machines à l’aide d’une clé USB bootable. J’ai ensuite configuré les différents paquets et utilitaires nécessaires à l’utilisation des commandes système et des applications.

Enfin, j’ai installé les différents outils et environnements de développement indispensables à l’utilisation des langages de programmation étudiés au cours du cursus.

## Compétence

Installer et configurer un environnement de développement

## Fonctionnalités

Le poste de travail permet :

- d’installer un système d’exploitation Linux ;
- de démarrer une installation depuis une clé USB bootable ;
- de configurer le système après son installation ;
- d’installer et gérer différents paquets ;
- d’utiliser les principales commandes système Linux ;
- d’installer les outils nécessaires au développement ;
- de configurer les environnements nécessaires à l’apprentissage de la programmation ;
- de disposer d’un environnement de travail fonctionnel pour les différents projets du cursus.

## Fonctionnalités principales

- Création et utilisation d’une clé USB bootable
- Installation d’un système Linux
- Configuration du système d’exploitation
- Installation et gestion de paquets
- Utilisation du terminal Linux
- Installation d’outils de développement
- Configuration d’environnements de programmation
- Préparation d’un poste adapté au développement informatique

## Technologies utilisées

- Linux
- Terminal
- Clé USB bootable
- Gestionnaires de paquets
- Outils et environnements de développement

## Objectif pédagogique

Ce projet a permis de pratiquer :

- l’installation d’un système d’exploitation ;
- la configuration d’un poste de travail ;
- l’utilisation du terminal Linux ;
- l’utilisation de commandes système ;
- l’installation et la gestion de paquets ;
- la configuration d’un environnement de développement ;
- l’installation d’outils nécessaires à la programmation ;
- la compréhension de l’environnement de travail d’un développeur ;
- l’autonomie dans la préparation et la maintenance d’un poste informatique.

## Remarque

Cette SAÉ m’a permis d’acquérir les bases nécessaires à la mise en place d’un environnement de développement fonctionnel. Les compétences acquises lors de ce projet ont ensuite été réutilisées dans les différents projets réalisés au cours de la formation.
